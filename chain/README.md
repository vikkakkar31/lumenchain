# LumenChain Devnet v0.1

This directory is the executable Cosmos SDK application for LumenChain.

## Target

- Cosmos SDK v0.50.x
- CometBFT v0.38.x
- `lumend` node/CLI
- `ulum` test denomination (`1 LUM = 1,000,000 ulum` as a UI convention)
- standard auth, bank, staking, distribution, mint and governance modules
- custom `participation` and `rewards` modules
- local five-validator testnet tooling

The application source is generated from the pinned Ignite CLI v28.11.0 scaffold and then committed by GitHub Actions. Ignite v28.11.x supports Cosmos SDK v0.50.x, and the generated app is subsequently owned by this repository.

## Local bootstrap

From the repository root:

```bash
bash scripts/bootstrap-chain.sh
```

If GitHub Actions is enabled, pushing the bootstrap workflow causes the same generation to happen automatically and commits the generated application to `main`.

## Five-validator devnet

After the chain source has been generated:

```bash
bash infrastructure/testnet/local-5-validator.sh
```

The script creates five isolated validator homes under `chain/.devnet/`, creates and combines genesis transactions, configures persistent peers, and prints the RPC endpoints.

## Important

This is a **development network**, not a production/mainnet deployment. Validator keys generated by the local script are disposable. Production deployment will require independent validator keys, deterministic genesis review, key management/HSM policy, sentry architecture, backups, monitoring, incident response, upgrade procedures, and an external security audit.
