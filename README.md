# LumenChain

LumenChain is a modular blockchain project focused on participation, rewards, wallet infrastructure, and supporting services.

## Repository Structure

- `chain/` — blockchain application, modules, protocol definitions, and tests
- `wallet/` — Android wallet and shared wallet components
- `services/` — faucet, indexer, relayer, and notification services
- `infrastructure/` — Docker, testnet, and monitoring configuration
- `explorer/` — blockchain explorer
- `docs/` — protocol and design documentation
- `security/` — security and incident-response documentation

## Status

Initial repository scaffold.

Implementation details should be added incrementally as the protocol and architecture are finalized.
