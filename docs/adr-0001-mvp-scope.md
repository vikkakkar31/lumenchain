# ADR-0001: LumenChain MVP Scope

## Decision

The first release is a mobile-first testnet focused on local wallet security, light-client verification, staking/delegation, and limited participation measurement.

## Explicitly out of scope

- Custom consensus
- Proof of personhood
- Privacy-preserving identity
- Useful-computation rewards
- Mainnet economics
- Public token sales
- Full mobile validator nodes
- Transferable participation rewards

## Rationale

This keeps the first implementation testable and reduces protocol, security, economic, privacy, and regulatory complexity.
